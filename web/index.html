From project to report.

Scan your project locally, then use the viewer to review the result.

  1. Install the CLI

    Download SCRAM for macOS, Linux, or Windows and put the executable on your PATH. If you have Go 1.23.4 or newer with its bin directory on your PATH, you can install from the terminal.

    go install github.com/0xsan7/scram/cmd/scram@v0.2.0

    Run scram --version to check the install. See the installation notes for verification instructions.

  2. Run a scan

    Open a terminal in your project folder. SCRAM reads supported dependency files and queries advisory data over the network.

    scram scan --format json > report.json

    Exit code 1 means the policy failed. You can still open the report. Exit code 2 means the scan could not finish. On Windows, use Command Prompt or PowerShell 7 for this command.

    Track what changed

    Run scram baseline update before making dependency changes. Your next scan compares findings with that saved snapshot.

  3. Open your report

    Choose report.json in the viewer. Start with the policy result and warnings, then inspect a dependency for its advisories.

    Go to the report viewer →
    Open it from the CLI

    If your build includes the view command, run scram view report.json and open the printed local link. For the published v0.2.0 release, use the browser viewer.

What is SCRAM?

SCRAM stands for Supply Chain Risk Assessment & Monitoring. It helps maintainers compare a dependency inventory with a saved baseline and decide whether new findings should block a change.

It supports npm, including Yarn and pnpm, Python, Go, and Rust. You can run scans locally or add SCRAM to a GitHub pull request workflow.

Your report stays here.

The viewer reads files in your browser. It needs no account and sends no report to a server.
