# Scanner and viewer regression tests, 21 November 2026

Tested in a temporary clone based on the GitHub release-readiness branch at
`3c3d016411ad448706f8084095405653f87922e7` on macOS arm64 with Go 1.23.4
and Node 24.21.0. Results apply to the local candidate.

| Reproduction | Corrected behavior |
| --- | --- |
| Add an npm dependency edge beside a Go module recorded only in go.sum, then run `why` on the Go module. Text and JSON claimed direct dependency. | The text reports an unknown path. JSON uses the component’s recorded direct flag and reports `path_known: false`. Direct and nested npm controls exercise the other two outcomes. |
| Read a valid SHA-256 integrity token through npm v1/v3, Yarn or pnpm. All four paths labeled it SHA-512, which could remove a legitimate checksum from an SBOM. | The reader retains each supported algorithm with a correctly sized digest. A test builds the CLI and checks the same bytes in CycloneDX and SPDX. |
| Read a Go module checksum already prefixed with `h1:`. | SCRAM preserves the original value. The tests also cover an unprefixed hex string that could otherwise be mistaken for a package checksum. |
| Open an inventory-only scan with no other warnings. The viewer displayed a plain policy pass with zero findings. | The scanner records that it skipped vulnerability matching. The viewer and text export surface the warning while preserving the actual license-policy decision. |
| Move a reported component from one risk bucket to another in the summary while keeping the total unchanged. | The viewer rejects contradictions in the scan or drift summary. Components with an omitted optional bucket still import. |
| Run a mutation selector that matches nothing or only a subset. Both previously replaced the full audit file, and an empty selection exited successfully. | A missing selector match fails. A filtered run preserves the last full result. |

## Local validation

- Full shuffled Go race suite passed, with 73.1% statement coverage. Go vet passed.
- All 23 fuzz targets completed at six seconds per target. The Go module checksum parser received a further 20-second run.
- All 78 mutations were killed. The matrix includes directness and path reporting in `why`, trend delta direction, inventory-only warnings, SRI labels and Go module hashes. The [result file](../../scripts/mutation_results.json) lists the outcomes.
- The corpus checker resolved 30,885 components across its fixture set. All 12 Python tests passed.
- All 15 Node checks passed, including the live CLI-to-viewer contract and the exact 5 MiB UTF-8, 10,000-component and 50,000-finding boundaries. The static viewer built successfully.
- Headless Chrome and Brave exercised the embedded loopback viewer with local synthetic data. Checks included invalid and oversized files, drag and drop, desktop pagination, mobile inspector focus, switching reports and byte-for-byte comparison of the downloaded summary with the displayed text. The [viewer instructions](../../web/README.md#regression-tests) describe the reusable test.
- The CLI cross-compiled for Darwin and Linux on amd64 and arm64, and Windows on amd64. Native runtime testing in this pass used macOS arm64.

The browser cases cover Chromium engines. Firefox, Safari, screen readers,
hosted CI, signing and deployment require separate verification.
