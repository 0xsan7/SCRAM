# v0.2.0 release validation

Released 2026-10-12 after explicit authorization to resume and fully release.
Stable source: `7a76788583ec43091e0397a39a5fbf4d1b017e25`.
Candidate source: `aeefc1d28bb27352e190103c16744f93e8b58a24`.
All previous releases, tags, and branches were retained.

## Source validation

- [Stable source CI](https://github.com/0xsan7/SCRAM/actions/runs/38229763900): all six platform/Go matrix legs, lint, corpus invariant, self scan, and SBOM validation passed.
- [Coverage and race detector](https://github.com/0xsan7/SCRAM/actions/runs/38229764072): passed.
- [Full-history secret scanning](https://github.com/0xsan7/SCRAM/actions/runs/38229763940): passed. Local gitleaks v8.30.1 used `detect --source=. --log-opts=--all --redact` before every push; a planted synthetic credential in an isolated repository produced exit 1.
- [Fresh fuzz and mutation run](https://github.com/0xsan7/SCRAM/actions/runs/38228379155): 22 targets fuzzed for 30 seconds each; 40/40 mutants killed, no survivors or invalid/broken mutants. The Go source is unchanged between that run and the stable tag.
- Local `go test ./...`, `go vet ./...`, and a 45-second `FuzzGoMod` run passed; the latter completed 1,127,031 executions. D48 records the original failing seed and its regression coverage.

## Stable verification

[Stable release CI](https://github.com/0xsan7/SCRAM/actions/runs/38230199537) passed. GitHub marks [v0.2.0](https://github.com/0xsan7/SCRAM/releases/tag/v0.2.0) as non-prerelease and `releases/latest` resolves to it. All 18 expected assets are present.

All five binaries passed SHA-256 and cosign verification using the exact identity `https://github.com/0xsan7/SCRAM/.github/workflows/ci.yml@refs/tags/v0.2.0` and GitHub's OIDC issuer. All certificates contained `7a76788583ec43091e0397a39a5fbf4d1b017e25`; all Go build records contained that revision and `vcs.modified=false`. A signature verified against a different repository identity was rejected. The native macOS arm64 binary printed version `0.2.0` and that exact commit. Both SBOMs parsed with seven components/packages.

`GOPROXY=https://proxy.golang.org go install github.com/0xsan7/scram/cmd/scram@v0.2.0` succeeded in an isolated output directory. The installed binary's Go build record names module version `v0.2.0`, and its help command executed successfully.

[Stable push smoke checks](https://github.com/0xsan7/scram-action-rc1-check/actions/runs/38230750429) passed on all five supported targets, using `uses: 0xsan7/SCRAM@v0.2.0` with default binary-version selection. Every run asserted JSON schema 2.0.0, denominator 65, and a score within 0–65.

[Stable unchanged PR](https://github.com/0xsan7/scram-action-rc1-check/actions/runs/38230772912) passed with zero new findings. Its [updated comment](https://github.com/0xsan7/scram-action-rc1-check/pull/3#issuecomment-6121400651) renders `21/65`.
[Stable new-finding PR](https://github.com/0xsan7/scram-action-rc1-check/actions/runs/38230776312) correctly failed for the introduced minimist advisories. Its [updated comment](https://github.com/0xsan7/scram-action-rc1-check/pull/4#issuecomment-6121461864) renders `25/65`, two new advisories, one new high and one new critical finding. Existing comment IDs were retained, proving updates rather than duplicate posting. The fixture PRs were closed without merging or deleting branches.

## Limits

These checks verify artifact integrity, keyless signing identity, source-commit metadata, and actual execution of all five release targets. They do not constitute a SLSA build attestation; that remains in ROADMAP.md with reachability, additional ecosystems, freshness/EPSS data, and wider CLI testing. No documentation site was added.
